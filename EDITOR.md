# Редактор цін ТМ «ПІФ» (Інструкція для власника сайту)

Оновлений сайт підтримує **миттєве редагування цін та фасувань** безпосередньо у браузері (як прямо на картках товарів, так і в зручній зведеній таблиці `p01`–`p14`).

## Як відкрити редактор цін

1. Натисніть кнопку **«Редактор цін»** у верхній панелі сайту, кнопку **«Увійти (Адмін цін)»** у футері, або відкрийте сторінку з параметром `?edit=1` / `#edit` / `?editprices=1`.
2. Введіть пароль із файлу `editor-config.json` (за замовчуванням: `changeme`). Доступ зберігається у вкладці браузера (`sessionStorage`).
3. Ви можете:
   - Змінювати ціни та назви фасувань (`500мл`, `1л`, `5л`) прямо на картках у каталозі або у бічній панелі **«Таблиця всіх цін»**.
   - Додавати або видаляти варіанти тари для кожного продукту.
   - Масово змінювати ціни у відсотках (`-10%`, `-5%`, `+5%`, `+10%` або довільний `%`).
   - Натиснути **«Зберегти та оновити сайт»**, щоб зберегти чернетку у `localStorage` браузера.

## Як опублікувати нові ціни на GitHub Pages для всіх відвідувачів

1. У панелі редактора натисніть **«Завантажити products.json»** (або **«Копіювати JSON»**).
2. Замініть файл `products.json` у репозиторії GitHub (`https://github.com/oranjevo-beep/pitftm-web`, гілка `main`) і зробіть commit та push.
3. Після автоматичного оновлення GitHub Pages нові ціни стануть видимими для всіх покупців.

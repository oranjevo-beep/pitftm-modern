# ТМ «ПІФ» — Офіційний сайт виробника побутової та промислової хімії (Нова версія)

Сучасний, швидкий та адаптивний вебсайт і B2B/роздрібний каталог продукції **ТМ «ПІФ» (ТОВ «Кодимський Райпостач», м. Одеса, з 2005 року)**.

## Що оновлено у новій версії
1. **Оригінальна фірмова кольорова гама (`style.css`)**:
   - За замовчуванням оригінальний бренд-синій `#339af0` (перемикач тем лишає смарагд / бірюзу / navy) (`#1b4332`, `#2d6a4f`, `#40916c`, `#52b788`, `#d8f3dc`) та теплий бурштиново-золотий акцент (`#e67e22`, `#d4af37`), а також додано перемикач тем у верхній панелі.
2. **Оригінальний логотип та реальні фото продукції**:
   - Підключено фірмовий логотип `images/logo-slide.png` у шапці сайту, блоці Hero та футері зі збереженням правильних пропорцій (`object-fit: contain`).
   - Усі 14 позицій каталогу (`p01`–`p14`) використовують реальні фото з попереднього сайту (`product-1.webp` … `product-16.webp`), а також фото-галерею в Hero та модальне збільшення фото (Lightbox).
3. **Покращена адаптація під усі пристрої (Mobile / Tablet / Desktop)**:
   - Мобільна нижня панель швидких дій (`Каталог`, `Опт -12%`, `Заявка`, `WhatsApp`) для смартфонів.
   - Перемикач вигляду каталогу: **Картки товарів** або **Компактна прайс-таблиця** (зручно для оптових клієнтів).
4. **Вбудований Редактор цін власника (`products.json`)**:
   - Кнопка **«Редактор цін»** у верхній панелі (або перехід за `?edit=1`). Пароль за замовчуванням: `changeme`.
   - Редагування цін прямо на картках або в таблиці, масова зміна у `%` (`-10%`, `-5%`, `+5%`, `+10%`), миттєве збереження та експорт готового `products.json`.

## Швидке створення нового репозиторію на GitHub

```bash
# 1. Синхронізувати локальну папку ./images/ з оригінальними фото (за потреби)
./sync-images.sh

# 2. Закомітити та створити новий репозиторій через GitHub CLI:
git add .
git commit -m "Update TM PIF website with original colors, real photos, and responsive polish"
gh repo create pitftm-web-v2 --public --source=. --remote=origin --push
```

Або якщо ви вже створили порожній репозиторій на GitHub.com:

```bash
git remote add origin https://github.com/<ВАШ_ЛОГІН>/<НАЗВА_НОВОГО_РЕПО>.git
git branch -M main
git push -u origin main
```

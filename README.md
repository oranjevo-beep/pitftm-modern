# ТМ «ПІФ» — сучасний каталог (Tailwind SPA)

Статичний сайт бренду побутової та професійної хімії **ТМ «ПІФ»** (Україна, з 2005).

## Що всередині

- **Односторінковий каталог** на Tailwind CDN + Inter: hero, каталог із фільтрами, B2B, про нас, контакти
- Чотири HTML-файли (`index`, `products`, `about`, `contacts`) — однакова SPA-оболонка (якірні секції)
- Дані товарів і цін у `products.json` (14 SKU); логіка + редактор цін у `index.js`
- Приватний редактор цін (пароль у `editor-config.json`, за замовчуванням `changeme`)
- Зображення: `images/p01.jpg`…`p14.jpg` + `opt_hero.jpg` (webp у JSON — опційні, у zip їх немає)

## Локальний перегляд

Потрібен простий HTTP-сервер (fetch `products.json` / `editor-config.json`):

```bash
python3 -m http.server 8080
# відкрити http://localhost:8080/
```

## Деплой

Підходить для **GitHub Pages** (гілка `main`, корінь) або будь-якого static host / FTP.

Після зміни цін у браузері: завантажте `products.json` з панелі редактора і закомітьте в репозиторій.

Докладніше: [EDITOR.md](./EDITOR.md).
